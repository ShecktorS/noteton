╔════════════════════════════════════════════════════════════════════════════╗
║                           USER EXPERIENCE FLOW                             ║
╠════════════════════════════════════════════════════════════════════════════╣
║                                                                            ║
║  1. User apre Settings                                                     ║
║  2. Vede sezione "Aspetto" con SegmentedButton (Light/System/Dark)        ║
║  3. Sotto, nuova sezione "Variante colore" con chip:                       ║
║     • 🔵 Midnight (cerchio blu + label)                                    ║
║     • 💜 Amethyst (cerchio viola + label)                                  ║
║  4. Tap su "Amethyst" → cambio ISTANTANEO di tutto il tema                ║
║  5. Persistenza automatica in SharedPreferences                            ║
║  6. Al prossimo avvio → tema purple viene riapplicato                      ║
║                                                                            ║
║  COMBINAZIONI POSSIBILI:                                                   ║
║  • Light + Midnight   (tema originale chiaro)                              ║
║  • Light + Amethyst   (viola chiaro)                                       ║
║  • Dark + Midnight    (tema originale scuro)   ← DEFAULT                   ║
║  • Dark + Amethyst    (viola scuro)             ← NUOVO                    ║
║  • System + qualsiasi (segue OS preference)                                ║
